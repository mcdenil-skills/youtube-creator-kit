# Презентация и суфлёр

Возьми согласованный сценарий. Один экран раскрывает одну мысль. Покажи результат или пример крупнее текста. Слайды идут в том же порядке, что сценарий.

- В зрительской зоне слева размести короткий заголовок и до четырёх элементов. Используй обложку для результата, список для шагов, две карточки для сравнения, цитату для проверенного источника, терминал для команды и финальную карточку для реального подарка или действия.
- Правая четверть содержит текст для чтения, техническую подсказку и название следующего блока. Призывы живут здесь и в отдельном суфлёре. Выноси CTA в зрительскую зону, если автор хочет показать конкретный подарок или ссылку.
- Заполни `blocks[].slide` по [контракту](../../../knowledge/inputs.md) и собери файлы командой `python3 creator.py prepare ПАПКА_РОЛИКА`.
- Открой `navigator.html` в браузере. Проверь каждый экран при 1920×1080, читаемость, стрелки, следующий блок и отсутствие переполнения слева. Шпаргалка справа может прокручиваться внутри своей колонки. Для записи в OBS захвати левую зону и настрой её положение в кадре. В `teleprompter.html` проверь пуск, паузу, скорость и кегль.
- После согласования презентации запусти `node tools/slide-animator/render.mjs ПАПКА_РОЛИКА/navigator.html`. Путь и отдельные номера слайдов можно передать с пробелами через кавычки. Рендер забирает только зрительскую зону. На выходе MP4, постер и PNG-слои для монтажа.

Перегенерация HTML и Markdown использует `production.json`. Правь источник, чтобы изменения пережили следующий запуск.
