# Подходящие дополнительные навыки

Основной процесс ведут три навыка в `.agents/skills/`. Они работают с инструментами из этого репозитория. Если нужно усилить отдельную часть, можно выбрать дополнительный навык.

- **Lead Magnets** помогает придумать конкретный полезный материал, который продолжает ролик и даёт зрителю повод перейти по ссылке. [Источник](https://github.com/coreyhaines31/marketingskills/tree/main/skills/lead-magnets)
- **Copy Editing** подсказал редакторский проход, встроенный в навык сценариста. Проверяем, как текст звучит вслух, что зритель получает от каждого блока и чем подтверждён результат. [Источник](https://www.skills.sh/coreyhaines31/marketingskills/copy-editing)
- **Remotion Render** пригодится, когда нужно менять анимацию, кодек или пакет для монтажа. Для обычного рендера в проекте есть готовая команда. [Источник](https://www.skills.sh/remotion-dev/skills/remotion-render)
