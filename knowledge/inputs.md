# Входы и выходы

## Подготовка к съёмке

Автор даёт тему, референс или расшифровку. Агент собирает бриф и заполняет `production.json` в папке ролика. Рабочий пример – [production.json](../examples/demo/production.json).

| Поле | Содержание |
| --- | --- |
| `title`, `audience`, `promise` | Тема, зритель и итог просмотра |
| `facts` | Проверенные факты с источниками |
| `cta.intro`, `cta.outro`, `cta.telegram_reason` | Реплика после хука, реплика в финале, причина подписки на Telegram |
| `blocks[].title`, `duration`, `beats` | Название блока, плановый хронометраж в `M:SS`, опорные точки |
| `blocks[].open_loop`, `transition`, `speech` | Что ждёт зрителя дальше, переход, абзацы для произнесения. Первый абзац первого блока – хук. Поля `cta` вставляются автоматически |
| `blocks[].slide.headline`, `points`, `cue` | Короткий заголовок, 1–4 зрительских элемента, техническая подсказка ведущему |
| `blocks[].slide.kind` | По умолчанию `list`. Дополнительно `cover`, `compare` с двумя карточками, `quote` с цитатой и необязательной подписью, `terminal` или `cta` |

Команда `prepare` выдаёт `scenario.md`, `navigator.html` и суфлёр в Markdown и HTML. В презентации справа доступен полный текст для чтения. Слева – только материал для зрителя. Длинная шпаргалка прокручивается внутри своей колонки. Анимация из `navigator.html` складывается рядом в `animation/`.

## После записи

Агент читает `transcript.txt` с отметками `[MM:SS]` или `[HH:MM:SS]` и пишет `publication.json`. Рабочий пример – [publication.json](../examples/demo/publication.json).

- `title`, `alternate_titles`, `description`, `thumbnail` – основной заголовок, два запасных, обычный текст описания и текст обложки.
- `chapters` – массив `{at, title}`. Используй 00:00 и отметки из расшифровки. Если передан `duration` в формате таймкода, сборщик проверяет длину последней главы. Если глав меньше трёх, они попадут в отдельные ориентиры. [Требования YouTube к главам](https://support.google.com/youtube/answer/9884579)
- `links` – подтверждённые автором `{label, url}`. Допустим пустой массив, когда ссылка не нужна.
- `hashtags` – 1–5 тематических хештегов с `#`. `tags` – отдельные ключевые слова для YouTube Studio, список может быть пустым.
- `pinned_comment`, `telegram`, `handout`, `promises` – закреп, пост, материал для зрителя и список обещаний.

Команда `publish` выдаёт единый `postproduction/youtube.md`, пост, методичку и список обещаний. Блок «Описание для YouTube» готов к копированию вместе с главами, ссылками и хештегами. Сравни его с финальным видео перед публикацией.
